v1.7.2 프로세스 감시 개선 릴리즈

전체 코드 감사로 보안 결함 3건과 버그 8건을 수정하고, 56개 단위 테스트와 CI로 회귀를 막습니다.

🔐

삭제 안전 규칙 강화

시스템 경로 정확 일치·트리 보호에 더해, 관리자 권한 삭제는 앱 잔여물이 실제로 존재하는 /Library 하위 트리의 하위 항목으로만 제한됩니다. 각 트리의 루트 자체는 어떤 경우에도 삭제되지 않습니다.

🧾

SHA-256 검증 자동 업데이트

HTTPS 와 GitHub 배포 호스트 허용목록을 강제하고, 내려받은 설치 이미지의 해시가 릴리스 다이제스트와 일치할 때만 마운트합니다. 검증할 수 없으면 자동 설치를 중단합니다.

🧪

56개 회귀 테스트 & CI

삭제 안전 규칙, 잔여물 매칭 오탐, 업데이트 검증, 번역 정합성을 단위 테스트로 고정했습니다. 모든 변경마다 빌드·테스트·서명 검증이 자동 실행됩니다.

🌐

4개 국어 완전 지원

한국어 · English · 简体中文 · 日本語. 진행 상태 문구와 알림까지 전부 번역되며, 언어별 번역 누락은 테스트가 상시 검사합니다.

📊

정직한 시스템 수치

커널 통계 조회에 실패하면 추정값을 만들어내지 않고 측정 불가로 표시합니다. 모니터링 도구가 조용히 거짓 수치를 보여주지 않도록 했습니다.

⚡

16-Worker 초고속 해시 엔진

16개 전용 워커 바운디드 병렬 슬라이딩 윈도우로 파일 시스템 교착상태 없이 대용량 파일 해시를 초고속 비교합니다.

Real-Time Monitoring

⚡ 실시간 시스템 자원 대시보드 & 메뉴바 미니 컨트롤러

Mac의 CPU, 메모리(App/Wired/Compressed), 디스크 여유 공간, 시스템 온도 및 배터리 전원 상태를 1초 단위로 감시합니다.

  • ✓ 원클릭 메모리 최적화: 비활성 메모리 및 가상 수거 영역 즉시 환수
  • ✓ 메뉴바 미니 컨트롤러: 상태바에서 실시간 RAM% 및 네트워크 업/다운로드 속도 조망
  • ✓ 프로세스 폭주 가드: 자원을 과하게 오래 점유하는 앱 감지 및 강제 종료 지원 (v1.7.0 부터 기본 꺼짐, 임계값·지속시간 설정 가능)
4-Tier Uninstaller Engine

🗑️ 4단계 스마트 앱 완전 삭제기

앱 파일 본체만 삭제해서는 지워지지 않는 Application Support, Caches, Preferences 등의 숨은 찌꺼기 파일까지 완벽하게 추적합니다.

  • ✓ 사전 권한 검증 (Pre-Auth): 비밀번호 오류나 취소 시 앱 본체를 포함해 어떤 파일도 삭제하지 않고 전체 중단
  • ✓ 4단계 폴백 엔진: Trash ➔ NSWorkspace ➔ Direct Delete ➔ Admin Privilege Escalation
  • ✓ 이중 이스케이프 방어: 셸과 AppleScript 두 레이어를 모두 이스케이프해 파일명을 통한 명령 주입을 차단
  • ✓ 시동 프로그램 관리자: 부팅 시 실행되는 백그라운드 에이전트 선택적 비활성화

🔐 안심하고 쓸 수 있는 이유

파일을 지우고 관리자 권한을 쓰는 앱인 만큼, "지우면 안 되는 것을 지우지 않는" 규칙을 코드로 고정했습니다.

🚫

4중 삭제 보호 계층

① 시스템 루트·홈 최상위 폴더 정확 일치 차단
② 시스템 트리 하위까지 경계 단위 차단
③ 심볼릭 링크 해석 후 판정
④ 관리자 권한 삭제는 화이트리스트 트리의 하위 항목만 허용

🛑

전부 아니면 전무 (All-or-Nothing)

앱 완전 삭제 시 관리자 권한이 필요한 항목이 있으면 삭제를 시작하기 전에 인증을 요청합니다. 인증에 실패하거나 취소하면 앱 본체를 포함해 어떤 파일도 삭제되지 않습니다.

✅

다운로드 무결성 직접 확인

모든 릴리스에 설치 파일의 SHA-256 체크섬을 함께 게시합니다. 아래 명령으로 직접 대조하실 수 있습니다.

shasum -a 256 MacOptimizationTool_Setup.dmg
